# Шаблон текстур рыб и удочек VenturaFishing

- Размер готовой текстуры: `64 x 64 px`.
- Цветовой режим: `RGB`, 8 bit.
- Фон: прозрачный.
- Формат экспорта: `PNG-24` с альфа-каналом.
- Оставляйте минимум 4 px пустого места от края. Рабочая область — `56 x 56 px`.
- Для pixel-art используйте Pencil размером 1 px, жёсткие края и без сглаживания.

## Работа в Photoshop

1. Откройте `fish-texture-template.psd` или `fish-texture-template-64x64.png`.
2. Включите сетку: **View → Show → Grid**.
3. В Preferences → Guides, Grid & Slices поставьте Gridline every `1 pixel`, Subdivisions `1`.
4. Рисуйте на слое `DRAW HERE`. Габаритную рамку и направляющие перед экспортом скройте.
5. Экспортируйте как PNG точно в `64 x 64 px`, не меняя Canvas Size.

Для удочки располагайте силуэт по диагонали внутри голубой безопасной области. Оставляйте прозрачный
зазор вокруг лески и кончика: иначе после уменьшения или в GUI они сольются с краем слота.

Красная рамка — граница холста, голубая — безопасная область, жёлтые линии — центр.
